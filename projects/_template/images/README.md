# Images Directory

This directory is for project-specific images, logos, and figures.

## Usage

- Add project logos or branding images here
- Store custom figures or diagrams for your capacity test report
- Reference images in the notebook using relative paths: `./images/filename.png`

## Example

If you have a project logo, place it here and reference it in the notebook header:

```markdown
<center><img src="./images/project_logo.png"></center>
```
